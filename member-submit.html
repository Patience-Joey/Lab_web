实验室成员信息登记

本入口面向已经加入 SPIN Lab 的新成员。提交资料后，相关信息将用于更新团队成员页面。

提交个人介绍

使用 GitHub 表单提交信息，可直接拖拽上传头像，并保留完整的资料记录。

1

填写资料

填写姓名、成员类别、个人简介和公开联系方式。

2

上传头像

把清晰的正面照片拖入头像栏，提交前检查预览。

3

完成登记

资料确认完成后，网站会自动更新成员介绍。

提交前请准备

  • 姓名与成员类别
  • 100–300 字个人简介
  • 清晰、比例合适的个人头像
  • 邮箱及个人主页（可选）
  • GitHub 主页（可选）
  • Google Scholar（可选）
打开成员登记表
提交内容和头像将公开显示在 GitHub 与实验室网站上，请勿填写手机号、身份证号、住址等隐私信息。提交需要登录 GitHub。
