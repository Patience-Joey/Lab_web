实验室成员信息登记

本入口面向已经加入 SPIN Lab 的新成员。提交后需由实验室管理员审核，审核通过后信息才会发布到团队成员页面。

提交个人介绍

使用 GitHub 表单提交信息，可直接拖拽上传头像，并能完整记录审核过程。

1

填写资料

填写姓名、成员类别、个人简介和公开联系方式。

2

上传头像

把清晰的正面照片拖入头像栏，提交前检查预览。

3

等待审核

管理员核对后批准申请，网站会自动更新并重新部署。

提交前请准备

  • 姓名与成员类别
  • 100–300 字个人简介
  • 清晰、比例合适的个人头像
  • 邮箱及个人主页（可选）
  • GitHub 主页（可选）
  • Google Scholar（可选）
打开成员登记表
提交内容和头像将公开显示在 GitHub 与实验室网站上，请勿填写手机号、身份证号、住址等隐私信息。提交需要登录 GitHub。
管理员审核说明
  1. 在 GitHub Issues 中核对申请人的身份、文字内容、头像和链接。
  2. 需要修改时直接请申请人在原 Issue 中编辑资料，不要先批准。
  3. 确认无误后添加 member-approved 标签。
  4. 自动化完成后会更新团队页面、触发 Pages 构建，并关闭该 Issue。
